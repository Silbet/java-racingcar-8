# java-racingcar-precourse

## 자동차 경주

자동차의 이름을 1대 이상 입력하면 무작위 값에 의해 자동차 경주 게임을 진행합니다. 진행 결과에 따라 우승자를 출력하는 프로그램입니다.

## 실행 방법

1. 자동차의 이름을 1대 이상 입력한다.
2. 무작위 값에 의해 진행할 전진 횟수를 입력한다.

## 입력

1. 자동차 이름 입력하기
    - 자동차 이름을 쉼표(,)로 구분해 입력받는다

      e.g.
      `rose,apple,cup`

    - [예외] 이름은 1자 이상, 5자 이하만 입력 가능하다.
    - [예외] 아무것도 입력하지 않으면 안된다.
2. 진행할 전진 횟수를 입력하기
    - [예외] 1 이상 값만 입력 가능하다.

## 핵심 기능

1. 자동차 경주 게임 진행
    - 0~9사이의 무작위 값에 의해 자동차는 전진한다.
    - 무작위 값이 4 이상일 경우 전진한다.

## 출력

1. 차수별 실행 결과 출력하기
    - 전진 결과에 따라 각 자동차의 전진 거리를 출력한다.

      e.g.
      ```실행 결과
      rose : -
      apple :
      cup : -

      rose : --
      apple : -
      cup : --
      ```

2. 우승자 출력하기
    - 우승자가 여러 명일 경우 쉼표를 이용해 구분한다

      e.g.  
      ```최종 우승자 : apple, cup```
